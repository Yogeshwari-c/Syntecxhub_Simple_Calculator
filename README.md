# Syntecxhub Simple Calculator

## Project Description

This is a command-line Simple Calculator developed using Python as part of the Syntecxhub Python Programming Internship.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero error handling
- Invalid input validation
- Repeated calculations
- Clear option
- Exit option

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python calculator.py
